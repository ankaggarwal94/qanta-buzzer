# Double-blind review notice

The TAE submission is double-blind. This repository is not anonymous: its owner, history, contributor table, and earlier project materials identify the author.

During review:

- do not place this repository URL in the paper, OpenReview metadata, author response, or other linked submission material;
- do not send reviewers to a named branch or release;
- use an anonymized supplementary ZIP or anonymous mirror if code is supplied for review;
- remove author names, account names, commit metadata, acknowledgments, private paths, and identifying provenance from that review artifact.

After author notification, the de-anonymized repository and release capsule can be linked publicly.
