## 1. What changes / what stays blocking

**Changes (only this):** for exactly the six `(idealized+performat, dp, field)`
triples `{signed_mean, abs_mean, mc_earlier, qa_earlier, same_step,
signed_mean_ci}`, a **VALUE** mismatch is routed to a new informational report
`known_divergence_informational` instead of the blocking `failures` list, so a
run that diverges *only* on these six now yields `verdict == "PASS"`. The six are
**still compared** and **still increment `checked`** (194 unchanged).

**Stays blocking (unchanged):**

| Surface | Behavior |
|---|---|
| Other 6 fields of same `dp` block (`n`, `signed_median`, `abs_median`, `mc_never_buzz`, `qa_never_buzz`, `signed_median_ci`) | blocking |
| `idealized+performat` · **`myopic`** block (all fields, incl. same field names) | blocking |
| All 7 OTHER nonrandom cells (both policies) | blocking |
| **Structure** of `idealized+performat` (a *missing* cell/field — even a carve-out field) | blocking (structural failure) |
| Random-K policy (structure blocking; values informational) | unchanged |
| Anchor bytes / cardinality pins / `EXPECTED_PARITY_CHECKED` (=194) | unchanged |
| Verdict formula `PASS iff not failures and checked==194` | unchanged (needs no edit) |

**Deliberate asymmetry vs Random-K:** Random-K values are *excluded from*
`checked`; the six carve-out fields *remain in* `checked` (still compared, still
counted) — only their failure-routing changes. This keeps the pinned `194`, the
R-077 "160+32" prose, and `_validate_parity_anchor` cardinality gates untouched
(smallest blast radius).
