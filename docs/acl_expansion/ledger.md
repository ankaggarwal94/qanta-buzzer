## Scope of verification

The executable bridge and interval calculations establish properties of realized menus and payouts under documented assumptions. The trusted base includes the source review, split provenance, Python and JSON libraries, pinned model and tokenization assets, the Lean compiler/runtime, proof checkers, sandbox, CPU arithmetic and FLINT's enclosure guarantees. The Python eligibility, ranking, tensor-learning and orchestration code has tests and monitored outputs. Its full semantics have **no end-to-end formal proof**. The foundational allowlist contains `propext`, `Quot.sound` and `Classical.choice`. Two clean offline Linux builds reproduced the production executable digest, and probes exercised its production client.
