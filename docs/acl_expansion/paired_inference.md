# Matched open-ended and IMCQA inference

`scripts/acl_paired_inference.py` consumes `Prepared` and builds one matched open-ended job and one multiple-choice job per actionable prefix. The two contexts have the same question substring and instructions for confidence and abstention. The MC context displays the realized ordered menu. The OE job ID depends only on the public question identity, split, source prefix index, template revision and prompt hash, so the same OE response can be joined to multiple menu arms. Each model call starts with fresh context.

The ordinary prompt bytes come from the `concise_json_v4` branch of `qb_data/jane_paired.py`. The optional IMCQA conditions use the original `forced` and `wait` renderers from `scripts/imcqa_wait_scoring.py`. Six SHA-256 test vectors were produced by executing those upstream renderers on the same Unicode fixture. The frozen JSON output constraint module is restored byte-for-byte at its original path. [Jane paired renderer, pinned](https://github.com/ankaggarwal94/qanta-buzzer/blob/c5981d913165f8dc24173c3ec8615b221cfc944d/qb_data/jane_paired.py) · [Upstream constrained decoder, pinned](https://github.com/ankaggarwal94/qanta-buzzer/blob/c5981d913165f8dc24173c3ec8615b221cfc944d/scripts/jane_output_constraints.py) · [IMCQA action renderer, pinned](https://github.com/ankaggarwal94/qanta-buzzer/blob/e2fad0d57bcd1e9e17ba36647ecda6ea3d2f2a5b/scripts/imcqa_wait_scoring.py)

For `--imcqa`, the game uses four choices and the five observed word endpoints floor(N·r/5), r=1,…,5. A ten-decile historical freeze uses indices 1,3,5,7,9 (zero-based). The adapter also accepts those five source prefixes directly. All four conditions use the same selected grid. The frozen payoff is +1,+0.8,+0.6,+0.4,+0.2 for correct answers, −1 for wrong, zero for WAIT/PASS and no discount or shaping. The adapter checks the five configured payouts to binary64 tolerance and rejects mismatched schedules. The other schedules use the ACL policy prompt and action environment. For K above four the generic paired export supports ordered string slot IDs, while the frozen CPU MC grammar uses A–D.

The protocols share prompt bytes with their pinned ancestors. This adapter has its own packaging, job IDs, learner arms and model selection. It does not reproduce the historical model experiment's GPU, Qwen/Mistral weights, cache-validation gates, cyclic rotations or label-swap conditions. Archive comparisons must bind the exact prompts and model settings separately. Balepur et al. examine how different multiple-choice scoring rules change rankings, which motivates keeping legal-action logit choices, open-ended answers and self-reported confidence as distinct measurements. [Scoring analysis implementation, pinned](https://github.com/nbalepur/mcqa-scoring/tree/d148c744e58ed520b1267e88b3ed65fd3bab9a6f)

The full historical public freeze contains 5,000 questions across calibration (1,000), selection (1,000) and test (3,000). The current renderer reproduced all 150,000 matched prompts byte-for-byte: 50,000 OE and 50,000 MC per menu condition, with ten prefixes per question. After assigning the historical ID schema and original order, streamed reconstruction recovered the frozen SHA-256 of the entire 271,957,519-byte main package. The transport separately reproduced the 10,000 choices-only controls (13,175,086 bytes) from their stored templates. The replay verified all 36 chunks, compressed XZ and compact JSON digests. It used only public text and metadata. This establishes compatibility of the public interface; identifying answer correctness, validating the private source oracle and measuring model behavior require other evidence. ## Run the three stages

In the Python environment for the optional CPU model backend, install `transformers==4.51.3`, `tokenizers==0.21.1`, `huggingface-hub==0.30.2`, `lm-format-enforcer==0.11.3` and `interegular==0.3.3`. The core menu, proof and generic paired-export paths do not load the grammar dependencies. The following commands work from the repository root on Windows and POSIX.

```sh
python -m scripts.acl_paired_inference export --config configs/acl_expansion/paired_imcqa_smoke.yaml --imcqa --out artifacts/acl_paired/public.json
python -m scripts.acl_paired_cpu_inference --public artifacts/acl_paired/public.json --out artifacts/acl_paired/responses.json
python -m scripts.acl_paired_inference score --config configs/acl_expansion/paired_imcqa_smoke.yaml --imcqa --responses artifacts/acl_paired/responses.json --out artifacts/acl_paired/grades.json
```

The public-only backend loads Apache-2.0 SmolLM2-135M-Instruct at the pinned revision and performs greedy, fresh-context CPU FP32 inference. Add `--local-only` after caching the model. MC and OE use the upstream prospective token grammar and require EOS on complete JSON. The IMCQA cases score each legal next action token at the assistant boundary `{"action":"` and preserve the legal logits. The model sees no evaluator answer rules, gold slot, suffix or other arm's prediction. [Pinned model and license](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct/tree/12fd25f77366fa6b3b4b768ec3050bf629380bac)

An external backend can return `{"schema":"acl-paired-responses-v1","responses":[...]}`. Each entry requires the exported `job_id`, `prompt_sha256` and parsed `response`. Supplying `raw_response` also checks the parse against the original generation. The scorer enforces complete coverage and the input dataset digest. OE grading uses conservative Unicode/case/whitespace-normalized source accepted, rejected and prompt rules. Unmatched answers produce `needs_review`; prompt matches produce `clarification_required`. Both retain null correctness. A WAIT in rounds 1–4 or PASS in round 5 is an action with null correctness. The per-prefix outputs retain counterfactual responses after the first stop. Aggregate trajectory metrics require first-stop replay and the original game payoffs.

The shipped smoke config produced 20 public contexts on one synthetic held-out question. The pinned model emitted five OE abstentions, five MC abstentions, five incorrect forced choices, four WAIT actions and a terminal PASS. All 20 generated responses passed their type and prompt bindings. The measured CPU run took 1.938 seconds to initialize the model and grammar and 8.605 seconds for inference. The trace preserves exact completion tokens, raw text, restricted logits, package versions and model file hashes. No hosted inference or cloud compute was used. [Blind inference trace](evidence/paired_smoke_trace.json) · [Grading receipt and per-prefix outcomes](evidence/paired_smoke_receipt.json)

The trace was reused after the exported horizon instructions were updated. All 20 paired jobs reproduced byte-for-byte, and regrading against the integrated source reproduced the recorded grading artifact.

The regression tests exercise the repaired cases, exact template bytes, OE menu independence, hash binding, complete grading coverage, unresolved clarification and terminal PASS.
