# Learned-value and fair-QA StopDFF reproduction

> **Scope note (R-038):** stopping-shift evidence in this repository concerns
> constructed QA reference trajectories — a constructed-reference sensitivity
> diagnostic. It does not assert observed open-ended decision preservation;
> the authoritative claim ledger lives under `reproducibility/colm_aims_2026/`.


This document covers source producers only. It does not claim that any
historical checkpoint, fair-QA JSON, learned-value export, or figure was
generated by the current source. Rebuild generated evidence after this source
is merged, and publish that evidence separately.

## Provenance contract

Run producers from a clean checkout of one exact commit. Each fair-QA or
learned-value export records:

- the exact producer Git commit and canonical producer-file SHA-256;
- whether that commit contains the exact producer bytes;
- hashes for numerical helper modules and relevant data/calibration inputs;
- exact checkpoint-byte hashes for learned-value evaluation; and
- the effective command line and output path.

The producers fail before publishing output when the producer or a relevant
dependency is dirty, the commit is missing, or the committed producer blob
differs from the executing script. The Modal wrapper verifies the host
producer before dispatch and passes the commit, status, and producer hash into
the tool-poor child container.

## Local learned-value smoke

Generate or select a train-fit calibration artifact first. The calibration
must identify `fit_split: train`; the smoke-only identity-calibration path is
not scientific evidence.

```bash
python scripts/train_stopdff_value_model.py \
  --smoke \
  --device cpu \
  --epochs 2 \
  --seeds 1 \
  --hidden 32 \
  --data-dir data/processed \
  --artifact-dir paper_exports \
  --out artifacts/value_model

python scripts/compute_stopdff_learned_value.py \
  --smoke \
  --device cpu \
  --checkpoint-dir artifacts/value_model \
  --data-dir data/processed \
  --artifact-dir paper_exports \
  --eval-split test \
  --out /tmp/stopdff_learned_value.json
```

While reviewing the source PR, keep generated checkpoints, JSON, Markdown,
LaTeX, and figures outside the branch.

## Local fair-QA smoke

The canonical run evaluates five declared QA references. `krandom` uses a
stable per-`(seed, qid, arm)` random stream, so question order and
`PYTHONHASHSEED` do not change candidate assignment.

```bash
python scripts/stopdff_fair_qa_retest.py \
  --data-dir data/processed \
  --calibration paper_exports/calibration_train.json \
  --fit-split val \
  --eval-split test \
  --reward-schedule power_mark \
  --qa-arms idealized,krandom,khard,kdisjoint,klex \
  --calibrations shared,performat \
  --n-test 30 \
  --n-val 30 \
  --num-bootstrap 100 \
  --seed 1 \
  --out /tmp/stopdff_fair_qa.json
```

`khard` selects and scores candidates in the same embedding space and is
circular by construction. `kdisjoint` and `klex` provide disjoint embedding
and lexical selectors. Recording those arms does not remove their
construct-validity limitations.

Continuation coverage is collected only for non-myopic DP traces. Its
`exact`, `pooled`, and `missing` tags are diagnostic and do not enter the
value calculation. Tests require coverage collection to preserve stop steps
and StopDFF values.

## Modal dispatch

```bash
RUN_ID=learned_value_<timestamp>

modal run --detach scripts/modal_stopdff_runner.py \
  --experiment learned_value_train \
  --artifact-subdir "$RUN_ID" \
  --gpu L40S \
  --smoke

modal run --detach scripts/modal_stopdff_runner.py \
  --experiment learned_value_eval \
  --artifact-subdir "$RUN_ID" \
  --gpu L40S \
  --resume \
  --smoke

modal run --detach scripts/modal_stopdff_runner.py \
  --experiment fair_qa \
  --artifact-subdir fair_qa_<timestamp> \
  --gpu L40S \
  --num-bootstrap 100 \
  --smoke
```

Training and evaluation share one new run subdirectory so evaluation resolves
the checkpoints written by training. `--resume` reopens that subdirectory for
the dependent evaluation without deleting it. A full evidence run must use a
new immutable subdirectory and must not overwrite the historical v5 execution
or stale PR #19 artifacts.
